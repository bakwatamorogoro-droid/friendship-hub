# Kukamilisha MUMSO AI kwenye GitHub/Vercel

## Matokeo
- AI itatumia `GEMINI_API_KEY` ya seva moja kwa moja kwenye Vercel bila kuiweka kwenye code ya umma.
- Mfumo utakubali majina ya kawaida ya ufunguo wa Gemini kwenye mazingira ya seva ili kuzuia hitilafu ya “ufunguo haujawekwa”.
- Ujumbe wa hitilafu utaeleza hatua sahihi kulingana na seva inayotumika.
- Lovable AI itaendelea kuwa njia ya pili ndani ya Lovable pekee.

## Utekelezaji
1. Tengeneza kisomaji salama cha ufunguo ndani ya handler kinachokubali `GEMINI_API_KEY` na `GOOGLE_API_KEY`.
2. Tenganisha hitilafu ya kukosekana kwa ufunguo na hitilafu ya kikomo cha matumizi.
3. Hakikisha ufunguo hauendi kwenye browser, GitHub, au bundle ya mbele.
4. Jaribu kidude cha AI na uthibitishe ujenzi hauna hitilafu.

## Kumbuka
GitHub huhifadhi code pekee; AI haiwezi kutumia siri kwenye GitHub Pages. Vercel lazima iwe na `GEMINI_API_KEY` kwenye Environment Variables na deployment mpya baada ya kuiongeza.
